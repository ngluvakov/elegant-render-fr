# Lovart image briefs - services listing

The services listing needs a coherent set of thumbnails. Each thumbnail should immediately reveal the service outcome, not just a nice room.

## Thumbnail system

- Same aspect ratio across all cards.
- Bright, realistic, low-clutter compositions.
- One strong subject per thumbnail.
- Enough contrast for a text overlay if Track C uses one.
- No readable text inside generated images.

## Service thumbnail prompts

| Service | Prompt direction |
| --- | --- |
| Interior render | Modern furnished apartment interior, natural daylight, realistic materials. |
| Exterior render | Residential exterior with facade, landscaping, and clear daylight. |
| Aerial render | Small development from above with plot context. |
| Yard and landscape render | Private yard with terrace, paths, planting, and soft light. |
| Photomontage | Proposed building integrated into a real street photo. |
| 2D floor plan | Clean plan drawing with furniture outlines and subtle dimensions. |
| 3D floor plan | Isometric apartment layout with walls, furniture, and finishes. |
| Site plan | Isometric plot plan with road, parking, and planting. |
| Animation | Three cinematic frames from one architectural camera path. |
| 360 virtual tour | Panorama-like interior with subtle interaction cue. |
| Virtual staging | Empty room transformed into a furnished room. |
| Virtual renovation | Existing room transformed into a renovated room. |
| Day-to-dusk | Exterior image transformed from day to dusk. |
| Item removal | Cluttered room cleaned for listing presentation. |

## Avoid

- Inconsistent color grading across cards.
- Dark images that hide the deliverable.
- People or pets as primary subjects.
- Stock-photo office scenes.
