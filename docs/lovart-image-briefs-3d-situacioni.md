# Lovart image briefs - 3D site plan

Use these briefs for 3D site plan imagery.

## Main image

Create an isometric 3D site plan for a small residential development. Show buildings, access road, parking, paths, planting, and outdoor zones. Use a clean white or light-neutral background and realistic but simplified materials.

## Detail image

Create a close crop showing entrances, paths, trees, and parking spaces from the same site plan style.

## Sales image

Create a developer-facing composition with a site plan render next to exterior render thumbnails, as if preparing a sales pack. Avoid readable text.

## Avoid

- Dense urban maps.
- Satellite imagery.
- Bright toy-like colors.
- Technical clutter that hides the layout.
