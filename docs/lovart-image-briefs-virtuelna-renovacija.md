# Lovart image briefs - virtual renovation

Use these briefs for virtual renovation imagery.

## Main before/after

Create a matched before/after interior scene. The before side shows an outdated but real room. The after side keeps the same camera and structure while updating floors, wall finish, kitchen or bathroom elements, lighting, and furniture style.

## Detail image

Create a close crop showing a renovated surface transition: new cabinetry, countertop, backsplash, and lighting with realistic shadows.

## Decision image

Create two renovation style options for the same room: warm minimal and soft contemporary. Keep layout identical so the viewer compares design direction.

## Avoid

- Moving windows or structural walls unless requested.
- Unrealistic budget signals.
- Overly luxury finishes.
- Changing the camera angle between before and after.
