# Lovart image briefs - item removal

Use these briefs for item removal imagery.

## Main before/after

Create a matched before/after room photograph. The left side has moving boxes, cables, small clutter, and an unwanted chair. The right side removes those items while preserving floor texture, wall shadows, and natural light.

## Detail image

Create a close-up where an object has been removed from a wall or floor area. The repaired surface should look natural and continuous.

## Listing image

Create a clean real estate listing room after item removal, with realistic imperfections preserved so it does not feel artificial.

## Avoid

- Changing furniture that should remain.
- Perfectly empty synthetic rooms.
- Warped floors or repeated texture patterns.
- Dramatic style changes.
