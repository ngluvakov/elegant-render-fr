# Lovart image briefs - aerial render

Use these briefs for aerial render imagery.

## Main image

Create a high-angle architectural render of a small residential building or development. Show the roof, plot, access road, neighboring context, landscaping, and parking. The scene should be clear enough for sales and planning conversations.

## Detail image

Create a crop focusing on roof geometry, balconies, courtyard, and pedestrian access.

## Portfolio image

Create an aerial render with a clean composition and realistic daylight, suitable for a service detail hero.

## Avoid

- Extreme drone altitude.
- Map-like flattening.
- Overly dramatic sunset.
- Text labels inside the image.
