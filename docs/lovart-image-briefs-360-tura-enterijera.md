# Lovart image briefs - interior 360 virtual tour

Use these briefs for interior 360 virtual tour imagery.

## Main image

Create a panoramic-feeling interior render from the centre of a furnished apartment. Show connected living, dining, and kitchen zones with realistic light and materials. The image should make the visitor feel they can look around the room.

## UI-neutral preview

Create a refined preview frame of an interior virtual tour with subtle navigation dots and no readable text. The room should remain the hero.

## Before delivery image

Show multiple panorama thumbnails from the same apartment arranged on a clean white surface, suggesting a complete tour package.

## Avoid

- Distorted fisheye framing.
- Dark mood lighting.
- Obvious stock furniture.
- Text inside the image.
