# Lovart image briefs - AI Studio

Use these briefs for AI Studio product imagery. The goal is to show practical image editing outcomes, not fantasy image generation.

## Workspace image

Create a clean desktop composition showing a property image before and after an AI-assisted edit. Include subtle UI-like panels without readable text. The edited result should look realistic and useful for real estate presentation.

## Object insertion image

Create a room scene where a referenced chair is inserted into an existing interior. The object should match perspective, scale, shadow, and light.

## Mask workflow image

Create a visual explanation of selecting an object area and replacing it with a new item. Use a soft translucent mask shape without text.

## History image

Create a grid of recent AI Studio results: virtual staging, item removal, day-to-dusk, and renovation. Keep all examples realistic.

## Avoid

- Sci-fi interface styling.
- Neon colors.
- Unrealistic generated artifacts.
- Text inside the image.
