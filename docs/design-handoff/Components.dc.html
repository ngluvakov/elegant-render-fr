Before / after reveal

replaces: before-after-reveal.tsx + demo-animation.ts — kept, retimed
Before After

Behavior spec

  • On viewport entry: one demo swipe — 50 → 100 (700ms) → 0 (900ms) → 50 (500ms), ease-in-out. Runs once.
  • After the demo: the 135° diagonal tracks the cursor (exact projection, no lag). Mouse leave eases back to 50.
  • Touch devices: demo plays on entry, then scroll-driven reveal.
  • Reduced motion: static 50/50 split, no demo.
  • Divider is a 0.8%-wide white blend line — recolored from the old warm glow.
