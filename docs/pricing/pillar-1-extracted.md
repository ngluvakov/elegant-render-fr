## Core concept — "Model-First"

> *We build the model once. You benefit every time.*
>
> Pricing reflects the marginal cost of production: the first output from a new 3D model carries the full model-build cost; each additional output from the same model costs progressively less. Volume, cross-item, and cross-service discounts all flow from this rule.

## Engineering notes for `src/lib/pricing/catalog.ts`

The pricing model is **non-trivial**. The calculator in `src/lib/pricing/calculate.ts` must handle:

1. **Tiered per-item pricing** — first item is one price, subsequent items are cheaper (e.g. `Static Exterior`: €250 then €48 each).
2. **Volume thresholds** — prices drop after N items (e.g. `360 Exterior`: €48/hotspot first 4, then €53 after).
3. **One-time percentage surcharges** — `Extended Model Surcharge` is +25% applied **once per 3D model**, regardless of how many cameras trigger it.
4. **Cross-category discounts** — Animation rates depend on whether an `Existing White Rook Model` or `Active Rendering Project` exists for that client. Requires a server-side context lookup at price-calculation time.
5. **Duration multipliers** — Animation has both a per-second rate AND a duration-band discount (e.g. 61–120s → 20% off the total).
6. **Percentage add-ons** — Day/Night (+30%), Seasonal (+40%), Rush (+50%) are % add-ons, not flat fees.
7. **Apartment-building layout discounts** — Progressive % off per additional unique layout (1st → 15% → 30% → 38% → 44%).
8. **Same-room vs. same-property vs. volume tiers** — Virtual Staging and Virtual Renovation have three different "scope" axes feeding the discount: same room, same property, volume threshold. The engine must know which axis applies.

### Open pricing questions for the client-facing flow

Some surcharges are **team-determined**, not client-determined. The v1 instant-price flow needs a rule for each:

| Surcharge | Client can self-declare? | Proposed v1 handling |
|---|---|---|
| **Extended Model Surcharge (+25%)** | ❌ No — only the team knows if a requested angle reveals unseen geometry | Show a clear "if your angle requires unseen geometry we'll confirm the one-time +25% surcharge before starting" disclaimer. Apply on team review. |
| **Active Rendering Project (47% off animation)** | ⚠️ Only if the user is logged in AND has an open order referencing that model | Lookup on price calculation. Anonymous checkout defaults to "Existing WR Model" (33% off) or "From Scratch" depending on flags. |
| **Apartment Layout discounts** | ✅ Yes — client declares the number of unique layouts | Calculator takes "unique layouts on this floor" as a config input. |
| **Rush Delivery (+50%)** | ✅ Yes — client picks it at checkout | Simple toggle in the checkout review step. |

These need a decision before Phase 3 (order flow) starts. Defaults above are safe starting points.
