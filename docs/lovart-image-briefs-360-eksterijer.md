# Lovart image briefs - exterior 360 virtual tour

Use these briefs for exterior 360 virtual tour imagery.

## Main image

Create a wide exterior architectural render prepared for a 360 virtual tour. Show a modern residential building, courtyard, paths, planting, and sky with balanced daylight. The composition should imply an interactive viewpoint without adding UI text.

## Interaction cue

Create a clean panorama preview on a white background with subtle circular motion cues and small viewpoint markers. Use a real exterior render as the content.

## Detail image

Create a close-up of an exterior facade corner with realistic glass, stone, landscaping, and soft environmental reflections.

## Avoid

- Heavy dusk scenes.
- Floating labels with readable text.
- Drone-only perspective.
- Game-like materials.
