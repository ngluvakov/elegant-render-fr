# Google Search Console Checklist

Search Console is partially prepared in the app:

- `https://elegantrender.rs/robots.txt` points to the sitemap.
- `https://elegantrender.rs/sitemap.xml` is generated by the App Router.
- The root layout can render Google's HTML verification meta tag from
  `GOOGLE_SITE_VERIFICATION`.

## Recommended Verification

Use DNS TXT verification if you have access to the domain DNS provider.
Vercel reports `elegantrender.rs` is using third-party nameservers:

- `ns739.adriahost.com`
- `ns740.adriahost.com`

Add the TXT record Google provides in Search Console, usually shaped like:

```txt
google-site-verification=...
```

DNS verification is best because it verifies the whole domain property.

## App-Based Fallback

If you choose the HTML tag method in Search Console, copy only the `content`
value from:

```html
<meta name="google-site-verification" content="COPY_THIS_VALUE" />
```

Set it in Vercel Production:

```env
GOOGLE_SITE_VERIFICATION=COPY_THIS_VALUE
```

Redeploy production after setting it, then click Verify in Search Console.

## Sitemap

After ownership is verified, submit:

```txt
https://elegantrender.rs/sitemap.xml
```

Admin shortcut:

```env
GOOGLE_SEARCH_CONSOLE_URL=https://search.google.com/search-console?resource_id=https%3A%2F%2Felegantrender.rs%2F
```
