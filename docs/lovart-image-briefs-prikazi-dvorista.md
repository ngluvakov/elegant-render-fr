# Lovart image briefs - yard and landscape render

Use these briefs for yard, garden, and outdoor-living renders.

## Main image

Create a realistic render of a private courtyard with terrace seating, planting, path lighting, lawn, and a calm residential facade. The result should help a homeowner understand layout and atmosphere.

## Detail image

Create a close-up of outdoor materials: stone paving, timber seating, planting beds, and soft sunlight.

## Seasonal image

Create a landscape render that feels usable across seasons: not too summery, not too bare. Keep planting believable for a maintained residential yard.

## Avoid

- Resort-style excess.
- Artificially perfect grass.
- Crowded garden ornaments.
- People as the subject.
