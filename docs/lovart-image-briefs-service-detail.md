# Lovart image briefs - service detail pages

Service detail imagery should make the specific deliverable obvious in the first viewport. Each page needs a hero image, one process image, one detail crop, and one before/after image where relevant.

## Shared hero pattern

Create a refined, realistic service image on a bright neutral canvas. The deliverable should be the focus: render, plan, tour, photomontage, virtual staging, or renovation. Leave quiet negative space for page text.

## Required variants

| Service | Hero subject |
| --- | --- |
| Interior render | Finished furnished room. |
| Exterior render | Finished building in realistic daylight. |
| Aerial render | Building and plot from a high angle. |
| Yard and landscape render | Outdoor living and planting layout. |
| Photomontage | Render integrated into a real site photo. |
| Floor plan | Clean 2D or 3D layout. |
| Site plan | Wider plot with access and landscape. |
| Animation | Sequence of camera frames from one project. |
| 360 virtual tour | Panorama preview from a real space. |
| Virtual staging | Empty-to-furnished transformation. |
| Virtual renovation | Existing-to-renovated transformation. |
| Day-to-dusk | Daylight-to-evening transformation. |
| Item removal | Cluttered-to-clean room image. |

## Avoid

- Generic architecture mood boards.
- Text rendered into the image.
- Placeholder UI screenshots.
- Single-color backgrounds that dominate the service.
